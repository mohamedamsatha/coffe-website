CAFÉ AURELIA WEBSITE
=====================

Files
- index.html  : page structure and content
- style.css   : visual design, responsive layout, animations
- script.js   : mobile navigation, menu filters, sample add-to-order toast

How to run on Windows
1. Extract the ZIP into a folder, for example D:\cafe-website
2. Open the folder.
3. Double-click index.html, or open it in VS Code and use Live Server.

Images and fonts
- Images currently load from Unsplash URLs, so an internet connection is required.
- Google Fonts are used for the typography.
- Replace the image URLs in style.css and index.html with your own images when ready.

Customise your café
- Change the café name and text in index.html.
- Update address, opening hours, prices and contact email in index.html.
- Change colours near the top of style.css under :root.
- Menu filters and add buttons work in the browser, but this is a front-end demo only.
  It does not send orders, process payments, or save reservations to a server.
